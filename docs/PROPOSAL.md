## 二、1. 项目简介（≤300 字）

「天健湖」是一个本地优先、多人协作的教育智能体平台，面向高中生、大学生与备考人群，把「教材学习—信息获取—记忆巩固—输出练习」收进同一个闭环：上传 Word/PPT/PDF/EPUB 教材，即可基于原文问答并标注页码；订阅高校教务处通知，第一时间拿到竞赛与截止信息；一键把微信群/QQ 聊天整理成待办与日程；用个人兴趣做联想助记并按遗忘曲线复习。情景式英语对话作为子项目，承担「输出侧」训练。

平台以账号体系与「私人/共享」双池组织数据：教材、公共笔记可共享给同学，个人 Key、错题与记忆卡留在私人池；模型 Key 自带、加密存储、数据不出本地，单机一条命令即可部署，无需 GPU。

## 二、2. 主要功能与智能体方案（≤500 字）

**主要功能**

1. **教材库与答疑** ✅：解析 docx/pptx/pdf/epub/md/txt/html，标题感知分块，保留页码与幻灯片号；扫描版 PDF 走 OCR；混合检索（BM25 + 向量 + RRF）；流式回答，逐句带可点击引用；检索不到就不调模型，直接说「教材未提及」。
2. **校园雷达** 🧭：订阅教务处/研究生院通知列表，增量抓取，LLM 抽取「竞赛/通知/讲座/考试、截止日期、面向对象」，进日历与提醒。
3. **群聊简报** ✅：粘贴微信群/QQ 记录 → 清洗降噪 → 一句话/重要事项/待办/日程 → 导出 TXT、MD、ICS、JSON。
4. **联想记忆** 🧭：先录喜好画像（游戏/动漫/音乐/梗/忌讳），再抽知识点，生成「画面 + 口诀」记忆卡，按 FSRS 曲线复习，可导出 Anki。
5. **情景式英语对话**（子项目）✅：场景生成 → 角色扮演 → 实时纠错（19 类闭合错误码）→ 生词入库 → 间隔重复 → 跨会话记忆复用。
6. **平台层** ✅：多用户账号与数据隔离、私人/共享双池、能力插件与 Agent 工具注册、任务中心、成本看板。

**智能体方案**：平台采用「薄内核 + 能力插件 + 工具注册表」。内核负责认证、存储、任务与模型接入；每个能力自带 manifest、路由、迁移与 Agent 工具，新功能不改内核即可接入。

- **答疑**＝检索 Agent + 引用校验：改写查询 → 双路召回 → RRF 融合 → 生成答案并强制逐句引用，无引用的断言降级为「教材未提及」。
- **雷达**＝抓取 Agent + 抽取 Agent：适配器优先、启发式兜底，LLM 只做字段抽取并校验重试。
- **记忆**＝画像 Agent + 助记 Agent + 事实守卫：助记卡必须能回指原文片段，不一致则丢弃重生成。
- **英语对话**（子项目）＝六 Agent 编排：仅首字阻塞、纠错并行、记忆后置，3 秒内完成。

## 二、3. 项目创新点或特色（200–300 字）

1. **学用一体，而非功能堆叠**：教材问答产生的疑难点、群聊产生的待办、英语对话产生的错误，都回流到同一套记忆与复习队列，学习数据产生复利。
2. **不信任模型自报的元数据**：引用必须能回指原文页码/幻灯片；错误分类用闭合枚举；模型给出的字符区间一律回验，对不上就丢弃。宁可少标，不能标错。
3. **兴趣锚定记忆**：把知识点映射到用户自己的游戏/动漫/音乐意象，生成可复述的「画面 + 口诀」，事实守卫保证不因联想而改变事实。
4. **私人/共享双池**：Key、错题、记忆卡进私人池；教材、公共笔记进共享池。一个班或一个课题组共用一份资料，权限按 owner 控制。
5. **可插拔、可验证**：能力插件 + 工具注册让功能可增量演进；测试、越权断言与端到端脚本可一键复跑。

## 三、2. 预期成果与效果验证（200–300 字）

**预期成果**：可本地或局域网多人访问的教育智能体 Web 应用；一套「教材—通知—记忆—输出」的学习闭环；可运行、可复跑的代码与测试仓库。

**验证方式**

- **技术指标**：检索 P95 ≤300ms；答案引用可回溯率 ≥95%；通知字段抽取准确率 ≥90%；记忆卡事实一致率 100%（不一致即丢弃）；首字延迟 P95 ≤2s（依赖模型）。
- **学习效果**：30 人两周试用，同一批知识点前后测正确率、记忆卡 7 日留存率、通知触达率。
- **工程指标**：测试通过率 100%；越权断言 7 条；单轮成本 ≤0.1 元并支持预算降级。
- **子项目指标**：英语对话沿用既有目标——纠错召回 ≥80%、误报 ≤15%、跨会话事实保留 ≥90%。

各项指标由随仓库提供的验证脚本自动出报告，可直接复跑；试用反馈用于迭代情景模板与助记策略。

## 三、3. 数据使用情况（勾选建议）

- ☑ **仅使用公开数据或自建数据** —— 教材由用户自行上传；通知来自高校公开页面；CEFR 词表、语法点、情景模板自建。
- ☑ **使用模拟或脱敏数据** —— 开发阶段的群聊样例与对话内容为构造数据。
- ☐ 可能涉及学校内部数据
- ☑ **可能涉及个人信息** —— 账号仅需用户名与密码；聊天记录与教材仅存本地；提供导出与删除。
