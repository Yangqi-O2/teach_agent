## ① 离线演示（无 Key，2 分钟）

1. 侧栏进入 **管理能力 → 情景英语**（或「设置 → 能力」），打开 **离线演示模式** 并保存；
2. 进入 **情景英语** 页面，领域填「一带一路」，等级 B1，点 **生成情景** → 出现 8 个话题；
3. 发一句 `I has went to the port yesterday`：
   - 回复流式出现（每次 2–3 帧）；
   - 右侧出现「候选生词」，消息下方出现「发现 1 处语法问题」；
   - 点用户消息里的虚线下划线 → 弹出知识卡（规则 + 例句）；
   - 点候选词「+」→ 生词本里出现该词（演示模式释义为占位）；
4. 刷新页面 → 对话仍在（会话已落库），**纠错下划线也在**（历史消息带 errors）；
5. 打开右侧「成本看板」→ 有轮次 / TTFT / token / 质量 flag；「错误档案」出现 1 个模式。

> 演示模式不产生任何真实模型调用，内容为假，**不要用它评价模型质量**。

## ② 真实模型验收（需要 OpenAI 兼容 Key，3 分钟）

1. **设置 → 模型接入**：填 Base URL（如 `https://dashscope.aliyuncs.com/compatible-mode/v1`）、
   模型名（如 `qwen-max`）、API Key，点「测试连接」→ 通过；
2. **管理能力 → 情景英语**：关闭离线演示模式；如需省钱可设置「预算降级模型」为 `qwen-turbo`；
3. 新建情景「一带一路」→ 生成情景应 5–10 秒内返回，话题标题与 beat 是英文、非硬编码；
4. 发一句有语法错误的英文，例如 `I has went to the port yesterday`：
   - 首字出现应较快（TTFT 看板可见）；
   - 回复以问句结尾（quality 规则：角色扮演要推进对话）；
   - 纠错标出的 `span` 必须能在你原句里找到（span 回验），改法 + 中文解释正确；
5. 点「+ 单词」存 2–3 个生词 → 生词本里有中文释义（真实模型模式下非空）；
6. 连聊 5 轮后：
   - 右侧「话题池」used_count 轮转；
   - 「情景记忆」出现 facts / beats，且开新会话仍能读到（跨会话记忆）；
   - 「错误档案」里同一错误只计一次/条消息，连续 5 次不再犯 → 移入「已改正」；
7. 导入一份 `port-notes.txt`（资料库 → 粘贴或上传）→ 再提问 `demurrage`，回复下方出现来源段落；
8. 发送第 31 轮（或把「每日对话轮数上限」调成 1）→ 提示今日配额用完（429）；
9. 换另一个账号登录 → 看不到第一个账号的情景会话、生词、错误档案（按用户隔离）。

## 常见问题

| 现象 | 查什么 |
|---|---|
| 生成情景报 409 `no_provider` | 「设置 → 模型接入」还没配供应商 / 没填 Key |
| 回复内容很假、provider 显示 `mock` | 能力设置里「离线演示模式」还开着 |
| 首字很慢 | 看「成本看板」TTFT；模型为大模型 + 长 system prompt 时正常 1–3 秒 |
| 回复一次性出现 | 反代/网关缓冲了 SSE：nginx 需 `proxy_buffering off`（参照 `deploy/nginx/tianjianhu.conf`） |
| 资料上传 415/422 | 只支持 docx/pptx/pdf/epub/md/txt/html；扫描版 PDF 无文字层会 422 |
| 每日轮数不够 | 能力设置里调大「每日对话轮数上限」 |
| 想看清成本 | 「成本看板」按设置里的单价估算；预算到 90% 会自动切 fallback 模型 |
